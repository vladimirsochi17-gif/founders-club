# Публичная тестовая среда

Статус 23.10.2026: отдельная среда собрана и работает локально; **постоянно работающая внешняя ссылка пока не получена**.
Временный адрес localhost.run открыл сайт и позволил зарегистрироваться в браузере, затем туннель оборвался (502 `no tunnel`). Не распространять этот старый адрес.
Cloudflare Tunnel не смог соединиться с edge по TCP/UDP 7844. Повторные SSH-подключения закрываются удалённой стороной; отмечались также ошибки DNS/TLS. На компьютере активен VPN-интерфейс `happ-tun`, но причинная связь не доказана. Настройки сети не изменялись.

## Что подготовлено

- [x] Отдельный Docker Compose-проект `founders-sandbox`.
- [x] Отдельная PostgreSQL `founders_sandbox`, собственные volumes базы и изображений.
- [x] Основная база, аккаунты, загрузки и локальный порт 8787 не передаются в песочницу.
- [x] Порт приложения 8791 привязан только к 127.0.0.1; порт БД наружу не опубликован.
- [x] Регистрация, сессии, черновики и тестовая оплата сохраняются в отдельной БД.
- [x] Тестовый код показывается на экране. SMTP отключён, настоящие письма не отправляются.
- [x] Секретная Secure/HttpOnly cookie привязывает тестовый аккаунт к браузеру регистрации. Чужой email и даже известный код сами по себе не дают доступ.
- [x] Вход в seed/admin-аккаунты закрыт; `/api/admin` отключён.
- [x] Баннер предупреждает о вымышленных данных, тестовых платежах и привязке аккаунта к браузеру. Индексация запрещена.
- [x] 27 автоматизированных тестов проходят; production-сборка проходит.
- [x] Проверка API работающего sandbox-контейнера: регистрация, защита от входа без browser cookie, сессия, создание и повторное чтение проекта, mock-платёж, запрет админки, logout.
- [x] По внешнему HTTPS в браузере проверены главная, регистрация, вход, открытие мастера проекта.
- [ ] Сохранение проекта через внешний адрес: туннель оборвался до завершения; проверка остаётся незавершённой.
- [ ] Устойчивая внешняя ссылка и повторная end-to-end проверка через неё.

Это песочница, не production. Email здесь — вымышленный идентификатор, не подтверждённая почта. После удаления cookies или перехода в другой браузер нужно создать новый тестовый аккаунт. Публикация после отправки остаётся за модерацией, автоматического одобрения нет. Остальные ранее отмеченные незавершённые функции проекта этим развёртыванием не исправлены.

## Запуск после восстановления туннеля

Туннель должен вести **только на 127.0.0.1:8791**, никогда не на основное приложение 8787 и не на PostgreSQL.
После получения новой HTTPS-ссылки:

```powershell
$env:SANDBOX_ORIGIN='https://НОВЫЙ-ВРЕМЕННЫЙ-АДРЕС'
npm run build
docker compose -f docker-compose.sandbox.yml up -d --build
node scripts/check-sandbox.mjs $env:SANDBOX_ORIGIN
```

`Dockerfile.sandbox` использует уже собранный локальный образ `founders-club-app:latest` и текущий `dist` (Linux-зависимости совпадают с основным приложением). При изменении зависимостей сначала пересобрать основной образ обычным Dockerfile.

`check-sandbox.mjs` отказывается работать с обычным приложением, проверяет флаг sandbox и создаёт вымышленные QA-аккаунты/черновики и mock-платёж. Проверка не списывает деньги. Для локальной диагностики можно передать третьим аргументом настроенный APP_ORIGIN:

```powershell
node scripts/check-sandbox.mjs http://127.0.0.1:8791 $env:SANDBOX_ORIGIN
```

Остановка без удаления тестовой БД:

```powershell
docker compose -f docker-compose.sandbox.yml stop
```

Для полностью автономной круглосуточной ссылки потребуется внешний хостинг; локальный туннель зависит от компьютера, Docker и сети. Бесплатный туннель также может менять адрес. При смене адреса необходимо обновить SANDBOX_ORIGIN и пересоздать только sandbox-приложение.
