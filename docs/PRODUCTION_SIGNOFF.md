# Production sign-off

Проект технически разворачивается на одном хосте через Docker Compose. Перед публичным коммерческим запуском владелец должен зафиксировать следующие решения.

| Область | Что передать/утвердить | Критерий готовности |
| --- | --- | --- |
| Домен | домен, DNS, reverse proxy | HTTPS, redirect HTTP→HTTPS, health-check снаружи |
| Email | SMTP, From, SPF/DKIM/DMARC | одноразовый код приходит в Inbox, не раскрывается API |
| Оплата | провайдер, merchant, webhook, возвраты, чеки | тестовая покупка, повтор webhook, отмена, refund и сверка пройдены |
| Telegram | bot username/token, chat, правила допуска | одноразовая ссылка, истечение, повторный вход и отзыв доступа пройдены |
| Legal | реквизиты оператора и утверждённые редакции | version IDs совпадают с фиксируемыми согласиями |
| Контент | реальные проекты и архивы ресурсов | demo seed отключён, файлы проверены, лицензии привязаны к версиям |
| Наблюдаемость | error tracking, metrics, alert target | алерт на 5xx/DB/down проверен контролируемым тестом |
| Backup | внешний зашифрованный storage и retention | выполнено тестовое восстановление БД + uploads |

## Минимальная приёмка после деплоя

1. `/api/health` возвращает `status=ok`, `database=ok`.
2. Главная, `/projects`, опубликованный `/p/:slug`, `/robots.txt`, `/sitemap.xml` возвращают ожидаемые HTTP-коды.
3. Неизвестный `/p/:slug` возвращает HTTP 404 и полезный экран.
4. OTP доставляется по SMTP; cookie содержит Secure/HttpOnly/SameSite.
5. Загрузка PNG/JPEG/WebP переживает restart приложения.
6. Повтор одного checkout idempotency key не создаёт второй платёж.
7. Два параллельных модератора не получают один кейс.
8. Backup скопирован вне хоста и восстановлен на чистой базе.

## Масштабирование

Текущая схема рассчитана на один application-host с persistent volume. Перед горизонтальным масштабированием файловое хранилище следует заменить S3-совместимым object storage, добавить очередь фоновых задач и централизованное rate limiting. PostgreSQL можно вынести в управляемый сервис без изменения доменной схемы.
