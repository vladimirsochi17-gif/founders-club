# Чеклист реализации и повторной проверки

Дата проверки: 22 октября 2026. Основание: Founders Club Design Specification 2.0.

Обозначения: `[x]` реализовано и проверено; `[~]` реализован безопасный каркас, нужен внешний провайдер или решение владельца; `[ ]` нельзя честно закрыть без внешних данных.

## Продукт и интерфейс

- [x] Реестр из 236 экранов/состояний сохранён; маршруты уникальны и проходят автоматическую проверку метаданных.
- [x] Реальные history URL, Back/Forward, deep link и восстановление query вместо hash-навигации.
- [x] Главная визуально сверена с исходным макетом при 1560×1024.
- [x] Мобильная версия проверена при 390×844: header, CTA, карточки, горизонтальные фильтры и footer доступны без горизонтального overflow страницы.
- [x] Loading, empty, error, restricted, toast, modal и dirty-guard состояния присутствуют.
- [x] Клавиатурный focus, skip-link, aria-label, focus trap модального окна и reduced-motion правила.
- [x] Шрифты и изображения локальны; в runtime нет зависимости от Google Storage или Google Fonts.
- [x] Production bundle разделён по зонам; основной JS около 286 КБ / 88 КБ gzip, тяжёлая карта проверки загружается лениво.
- [x] Публичная ссылка проекта использует нормальный canonical URL.

## Авторизация и безопасность

- [x] Email OTP с 10-минутным сроком, пятью попытками, HMAC-хешем и rate limit.
- [x] Production требует SMTP; локальный код `123456` отключается в production.
- [x] Случайные session tokens хранятся только в хешированном виде.
- [x] Cookie: httpOnly, sameSite=lax, secure в production, срок 30 дней.
- [x] Logout отзывает сессию на сервере.
- [x] RBAC для moderator/admin/superadmin и закрытые `/api/admin/*`.
- [x] Helmet CSP, запрет X-Powered-By, лимиты JSON/upload и единый безопасный error envelope.
- [x] Контейнер приложения работает от пользователя `node`; production включает read-only root, no-new-privileges и drop capabilities.

## База данных

- [x] PostgreSQL 17 с автоматическими транзакционными миграциями.
- [x] Ограничения целостности, внешние ключи, partial unique и индексы внешних ключей.
- [x] Пользователи, сессии, коды, подписки, платежи, проекты, участники, медиа, модерация, голоса, отзывы, жалобы, ресурсы, загрузки, промо, Telegram, audit/events.
- [x] Оптимистичная версия решения модерации исключает повторное конфликтующее решение.
- [x] `FOR UPDATE SKIP LOCKED` исключает выдачу одного кейса двум модераторам.
- [x] Идемпотентный payment order и уникальная атомарная бронь промо-слота.
- [x] Том БД и том медиа переживают перезапуск контейнеров.

## Рабочие пользовательские функции

- [x] Вход/регистрация по коду и гидратация кабинета из серверной сессии.
- [x] Серверная синхронизация UI state с локальной страховочной копией.
- [x] Выбор тарифа, два обязательных согласия, локальный mock checkout, активация и отмена продления.
- [x] 7-шаговый project wizard, автосохранение черновика и серверная отправка в модерацию.
- [x] Реальная загрузка, порядок и удаление изображений проекта.
- [x] Лимиты активных проектов Founder/Plus проверяются на сервере.
- [x] Голос с toggle-уникальностью, отзыв upsert и приватная жалоба модерации.
- [x] Лицензия ресурса и история скачиваний сохраняются после отмены подписки.
- [x] Админская очередь, claim, approve/revisions/reject и audit log покрыты интеграционным тестом.
- [x] Публичный API отдаёт только published проекты.
- [~] Скачивание выдаёт лицензию и безопасный demo-файл; коммерческие ZIP-архивы владелец продукта ещё не предоставил.
- [~] Promotion reservation реализован в БД/API; реальная оплата и рекламная маркировка зависят от выбранного провайдера и юридического решения.

## SEO и эксплуатация

- [x] Серверные title/description/canonical/robots для публичных и приватных маршрутов.
- [x] `/robots.txt`, динамический `/sitemap.xml`, HTTP 404 для отсутствующего `/p/:slug`.
- [x] `/api/health` проверяет приложение и реальное соединение PostgreSQL.
- [x] Docker multi-stage build, healthcheck, restart policy и production override.
- [x] Скрипт полного verify и HTTP smoke всех уникальных маршрутов реестра.
- [x] Скрипт раздельного backup PostgreSQL и файлов.
- [x] `npm audit --omit=dev`: 0 известных уязвимостей на момент проверки.

## Внешние блокеры production-запуска

- [ ] Утвердить платёжного провайдера, merchant account, webhook secret, возвраты и чеки.
- [ ] Передать домен/DNS и выбрать reverse proxy/сертификат.
- [ ] Передать SMTP-реквизиты и проверить доставляемость/DMARC/SPF/DKIM.
- [ ] Создать Telegram-бота/клуб, правила допуска и одноразовые invite links.
- [ ] Утвердить оферту, privacy, лицензии, возвраты, рекламу и данные оператора.
- [ ] Передать реальные Design Vault/Arsenal/Launch Kit архивы и их версии лицензий.
- [ ] Выбрать продуктовую аналитику и политику согласия на cookies/events.
- [ ] Утвердить тарифы, лимиты Plus, правила upgrade/proration и промо-цены.

Эти пункты не замаскированы demo-данными: production по умолчанию отказывает в реальной оплате и не обещает Telegram/юридические условия до подключения владельцем.
